## 2. 共通レイアウト

```
┌──────────────────────────────────────────────────────────────┐
│ ヘッダ (glass-header, sticky)                                   │  ← Header コンポーネント
│ ┌────────────────────────┬─────────────────────────────────┐ │
│ │ 漫画下载管理器           │ [设置][Komga][多选][更新状态]    │ │ (デスクトップ)
│ │ 总计:N | 已下载:N | 待下载:N │ [同步][下载全部(N)]          │ │
│ └────────────────────────┴─────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────┤
│ タブバー: [📚我的收藏] [✨最近更新]                             │  ← AppTabs
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  タブコンテンツ（グリッド or 作者別セクション）                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
       （モバイル時は右上に浮動メニューボタン SC-05）
```

### ヘッダ項目（デスクトップ）

| 項目 | 種別 | 動作 | 表示条件 |
|------|------|------|---------|
| タイトル「漫画下载管理器」 | テキスト | — | 常時 |
| 統計「总计/已下载/待下载」 | テキスト | 件数表示 | 常時 |
| 设置 | ボタン | SC-03 を開く | 常時 |
| Komga | ボタン | `http(s)://<host>:25601` を別タブで開く | 常時 |
| 多选 / 退出 | トグル | 選択モード切替 | 常時 |
| 删除 (N) | ボタン | 一括削除 | 選択モード且つ選択 > 0 |
| 更新状态 | ボタン | FN-SCAN 実行（スピナー表示） | 常時 |
| 同步 | ボタン | 現タブに応じ同期実行（進捗% 表示・実行中 disabled） | 常時 |
| 下载全部 (N) | ボタン | 現タブの未 DL を一括 DL | 非選択モード且つ待 DL > 0 |

> 同期ボタンは**現在のタブ**で対象が変わる（収藏タブ→`/api/sync`、更新タブ→`/api/sync-recent-updates`）。進捗は SSE から `(NN%)` または ` - メッセージ` を付記。

## 3. SC-01 メイン画面 / 我的收藏タブ

### 概要
お気に入り漫画を一覧表示。作者別グルーピング / フラットグリッドを切替可能。各漫画を DL・削除・選択できる。

### 表示モード
| モード | 条件 | レイアウト |
|--------|------|-----------|
| ローディング | `isLoading` | 「加载中...」 |
| 空 | `authorGroups.length===0` | 「还没有漫画数据，请点击"同步收藏夹"按钮」 |
| 作者別 | `groupByAuthor=true` | 作者セクション（§6）を更新日降順で並べる |
| グリッド | `groupByAuthor=false` | 漫画カードを更新日降順でグリッド表示 |

### ソート
- グリッド: `updated_at` 降順。
- 作者別: 各作者内を `updated_at` 降順、作者間も最新作の `updated_at` 降順。

### イベント
| 操作 | ハンドラ | API | 後処理 |
|------|---------|-----|--------|
| DL ボタン | `handleDownloadManga` | `POST /api/download/{id}` | `reload()` |
| 削除 | `handleDeleteManga` → SC-04 | `DELETE /api/manga/{id}` | 状態から除去 |
| カード選択 | `handleToggleSelect` | — | 選択 Set 更新 |
| カードクリック（非選択） | — | — | `manga_url` を別タブで開く |

> 収藏タブでは `onFavorite` を渡さないため、**収藏（ハート）ボタンは表示されない**設計。

## 4. SC-02 メイン画面 / 最近更新タブ

### 概要
お気に入り作者の新作（`recent_updates`）を表示。ヘッダに「N/M 已下载」を表示。タブ切替・同期完了時に再読込。

### 表示
| 状態 | 表示 |
|------|------|
| 空（`updates.length===0`） | 「暂无收藏作者的更新」 |
| 作者別 | 作者セクション（`allowFavoriteWhenNotDownloaded=true`） |
| グリッド | 漫画カード（同上） |

### イベント
| 操作 | ハンドラ | API | 特記 |
|------|---------|-----|------|
| DL | `handleDownloadFromUpdate` | `POST /api/download-from-update/{update_id}` | ローカル DL 中 Set で二重防止、完了後 `reload()` |
| 一括 DL（ヘッダ「下载全部」） | `onDownloadAllRef.current` | 上記を `pendingUpdates` 全件に逐次実行 | ref 経由で親から起動 |
| 収藏 | `handleFavoriteManga` | `POST /api/add-to-favorite` | 未収藏作品で表示、完了後 `reload()` |

> 待 DL 件数（`pendingUpdates.length`）を親へ通知し、ヘッダの「下载全部(N)」に反映。

## 5. 共通部品：漫画カード

[manga-card.tsx](../frontend/features/collection/components/manga-card.tsx)。SC-01/SC-02 共通。

### レイアウト
```
┌───────────────┐
│●            ✕ │  ← 左上:状態バッジ / 右上:削除(ホバー時, DL 済みのみ)
│  [カバー画像]   │  ← showPreview=true 時のみ（aspect 2:3, 最大 120px）
│               │     中央: DL ボタン(未 DL, ホバー時) / 収藏ボタン
│───────────────│
│ タイトル(2 行)  │
│───────────────│
│ 📖N页 💾サイズ ⏰日付│
└───────────────┘
```

### 表示項目
| 項目 | ソース | 整形 |
|------|--------|------|
| カバー | `preview_image_url`（無→`/placeholder.svg`） | `showPreview` 時のみ |
| タイトル | `title` | 2 行クランプ |
| 页数 | `page_count`（無→0） | 「N页」 |
| ファイルサイズ | `file_size` | MB 換算 2 桁（無→N/A） |
| 更新日 | `updated_at` | `zh-CN` ロケール日付（無→N/A） |

### 操作・分岐
| 要素 | 表示条件 | 動作 |
|------|---------|------|
| カードクリック | 常時 | 選択モード→選択トグル / 通常→`manga_url` を別タブ |
| DL ボタン（中央・円形） | 非選択 且つ 未 DL 且つ `onDownload` | `onDownload(manga)`（DL 中はスピナー） |
| 収藏ボタン（ハート） | 非選択 且つ 未収藏 且つ `onFavorite` 有 | `onFavorite(manga)`（未 DL 時は右上小、DL 済み時は中央大） |
| 削除ボタン（右上✕） | 非選択 且つ DL 済み 且つ `onDelete` | SC-04 を開く（ホバーで出現） |

## 7. SC-03 設定ダイアログ

[settings-dialog.tsx](../frontend/components/settings-dialog.tsx)。最大幅 500px のモーダル。

### 項目
| 項目 | 種別 | 内容 | 永続化 |
|------|------|------|--------|
| 手动设置漫画网站链接 | URL 入力 | サイトドメインの手動指定 | `PUT /api/settings`（サーバ DB） |
| 显示预览图 | スイッチ | カバー画像表示 ON/OFF | クライアント状態のみ |
| 按作者分类 | スイッチ | 作者別グルーピング ON/OFF | クライアント状態のみ |

### 動作
- オープン時に `GET /api/settings` で現値ロード。
- 「保存链接设置」で URL のみ保存（成功/失敗トースト、成功時クローズ）。表示オプションは即時反映（保存不要）。
- バリデーション（サーバ）: `http://`/`https://` で始まらない場合 400。

## 8. SC-04 削除確認ダイアログ

漫画カード内の固定オーバーレイ。

```
┌──────────────────────────┐
│ 确认删除                  │
│ 确定要删除《タイトル》吗？  │
│ 此操作无法撤销。           │
│            [取消][确认删除]│
└──────────────────────────┘
```

- 「确认删除」→ `onDelete(manga)` 実行 → カードを状態から除去。
- 一括削除はネイティブ `confirm()` ダイアログを使用（カード単体削除とは別経路）。

## 9. SC-05 モバイル浮動メニュー

[mobile-menu.tsx](../frontend/components/layout/mobile-menu.tsx)。画面幅 < 1024px（lg）時、右上に浮動ボタンを表示し、デスクトップヘッダの操作（设置/同步/下载全部/多选/更新状态/表示切替）を集約する。

- ヘッダはモバイル時、タイトルと統計のみ表示。
- スクロール連動でヘッダを自動表示/非表示（下スクロールで隠す、上スクロールで出す、最上部で常時表示）。

## 10. 状態表示・インジケータ仕様

漫画カード左上のバッジ（[manga-card.tsx:96](../frontend/features/collection/components/manga-card.tsx#L96)）:

| 色 | 条件 | 意味 |
|----|------|------|
| 🟢 緑（✓） | DL 済み 且つ 収藏済み 且つ 非 DL 中 | 完了 |
| 🟡 黄（✓） | 未収藏（`allowFavoriteWhenNotDownloaded` 時） | DL 済みだがサイト未収藏 |
| 🔵 青（スピナー） | DL 中 | ダウンロード中 |
| 🟣 プライマリ（✓） | 選択モードで選択中 | 選択済み |

カード枠: DL 済みはプライマリ系グラデーション枠、選択中はリング表示。
